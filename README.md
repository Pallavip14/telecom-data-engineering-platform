# TeleConnect Data Engineering Platform

An end-to-end personal data engineering project simulating a telecom company's data platform.

## Objective

Build a production-style data pipeline that demonstrates:

- Python
- SQL
- ETL
- PostgreSQL
- Data Warehouse
- Data Quality
- Airflow
- dbt
- PySpark
- AWS
- Kafka
- AI integration
